# 대한민국 정부 디자인 시스템 테마 및 컴포넌트

[English](README.en.md)

🇰🇷 [대한민국 정부 디자인 시스템](https://www.krds.go.kr/)에서 영감을 받은 테마와 컴포넌트입니다. 정부 디지털 서비스와 웹 앱을 설계하고 구축하는 데 필요한 원칙, 지침, 코드를 제공합니다.

## 패키지

| 패키지 | 스택 | 설명 |
|---|---|---|
| [`@gracefullight/krds`](packages/krds) | MUI v7 | Material UI 테마 + 컴포넌트 |
| [`@gracefullight/krds-tw`](packages/krds-tw) | Tailwind v4 + Base UI | shadcn 호환 헤드리스 컴포넌트 |
| [`@gracefullight/krds-tokens`](packages/krds-tokens) | — | 디자인 토큰 (색상, 타이포그래피, 간격) |
| [`@gracefullight/krds-icons`](packages/krds-icons) | React | 아이콘 세트 |

## 주요 특징

- KRDS 타이포그래피 및 간격 규칙 적용
- 접근성 및 대비 친화적인 색상 팔레트
- KRDS의 사용자 중심 디자인 가이드라인에 맞춘 UI 컴포넌트
- 확장과 커스터마이징이 쉬움
- 빠른 개발을 위한 사전 제작된 UI 컴포넌트
